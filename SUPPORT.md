# Optional paid help

## Redacted log classification pilot

A possible paid pilot is a review of one redacted build-log set and project-specific classification rules. Deliverables could include fixture-based results, documented classification mistakes, and a CI integration example.

Recurrence scores are not calibrated flaky-test probabilities. Autonomous repairs are not included.
